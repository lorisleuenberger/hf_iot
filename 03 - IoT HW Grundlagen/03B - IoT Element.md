# 03B - IoT Element

**Anforderung:** Sie können erklären was ein IoT Element ist. Und machen Beispiele dazu. Welche haben Sie selber in der Firma oder Zuhause im Einsatz?

Ein IoT Element besteht immer aus:
- Sensor oder Aktor
- Gateway

### Sensoren
Ein Sensor erfasst etwas aus seiner Umgebung und wandelt es in ein elektrisches Signal um. Diese Signale können dann weiterverarbeitet werden.
Dies nennt man dann auch Data End Points.

### Aktoren
Ein Aktor ist quasi das Gegenteil eines Sensors. Er wandelt digitale Signale in etwas physisches um. Das kann ein z.B. ein Motor sein oder ein Magnet,
oder etwas ganz simples, wie eine LED Statusleuchte.

### Gateway
Der Gateway ist grundsätzlich dazu da, um die Daten internetfähig zu machen und weiterzuleiten, oder Befehle entgegenzunehmen. Hier gibt es aber unterschiedliche
Ansätze. Man kann entweder Daten nur strikt weiterleiten und die ganze Logik auf einem Server verarbeiten; oder man verarbeitet gewisse Signale direkt auf dem
Gateway (z.B. Status LED oder Alarm Sound bei kritischen Messwerten).
