# 03B - Sensoren und Aktoren

**Anforderung:** Sie kennen verschiedene Sensoren und Aktoren. Was ist der Unterschied? Sie können dies in eigenen Worten erläutern.

Sensoren erfassen Informationen aus ihrer Umgebung und geben diese als elektrische Signale weiter. Ein Temperatursensor misst zum Beispiel die Temperatur, ein Lichtsensor die Helligkeit und ein Bewegungssensor erkennt Bewegungen.

Aktoren machen dagegen etwas sichtbar oder bewegen etwas. Sie erhalten ein Signal von einem Mikrocontroller und führen daraufhin eine Aktion aus. Beispiele dafür sind eine LED, die leuchtet, ein Motor, der sich dreht, oder ein Summer, der einen Ton erzeugt.

Der Unterschied ist also: Sensoren liefern Daten über die Umwelt, während Aktoren aufgrund dieser Daten eine Handlung ausführen. Ein Beispiel: Wird es mit einem Lichtsensor dunkel erkannt, kann der Mikrocontroller eine LED als Aktor einschalten.
